# RetroToon Streaming Starter

A React + Vite + TypeScript prototype with Supabase auth, catalogue, watchlist, viewing progress, and an admin upload screen for videos you own or are authorized to distribute.

## Important hosting reality
- Supabase Free Storage is limited; it is suitable for small tests, not a large catalogue of long episodes.
- Browser uploads here use a simple upload request and are not resumable. Large uploads need a provider with resumable uploads or a backend upload flow.
- Supabase Storage stores files; it does not transcode video into adaptive HLS. This starter plays uploaded browser-compatible MP4 files via the HTML video element.
- Do not upload or distribute Chutti TV episodes unless you have permission from the rights holder. Possessing a copy does not automatically grant streaming rights.
- Never put a Supabase service-role key in frontend code. Use only the publishable/anon key here and enable RLS.

## Setup
1. Create a Supabase project.
2. In Supabase SQL Editor, run `supabase/schema.sql`.
3. In Storage, create a **public** bucket named `cartoon-posters` (for demo posters). Create a **private** bucket named `episodes`.
4. In project Settings -> API, copy the project URL and publishable/anon key.
5. Copy `.env.example` to `.env.local`, then fill in the values.
6. In Supabase Authentication settings, configure your local and deployed Site URL / redirect URLs.
7. Install Node.js LTS if needed, then run:
   ```bash
   npm install
   npm run dev
   ```
8. Open the local URL printed by Vite. Register a user. In Supabase SQL Editor, promote your own account to admin:
   ```sql
   update public.profiles set role = 'admin' where id = 'YOUR_AUTH_USER_UUID';
   ```
   Find your UUID under Authentication -> Users.
9. Deploy to GitHub and import the repo into Vercel. Add the two VITE_ environment variables in Vercel and redeploy.

## Uploading episodes
Sign in with your admin account, open `/admin`, and upload a small MP4. The file is stored in private Supabase Storage; a signed playback URL is generated by the app. The signed URL expires after one hour. This simple upload is for small test files only.
